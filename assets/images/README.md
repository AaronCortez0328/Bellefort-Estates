# Where to put images

| Folder | What goes here | Website section |
|---|---|---|
| `logo/` | Bellefort logo (PNG or SVG, transparent background if possible) | Header, footer |
| `hero/` | Big wide shots: main gate, aerial view, streetscape | Top banner |
| `linear-park/` | The linear park behind the homes | Linear Park feature |
| `houses/charlotte/` | Charlotte: exterior, interiors, floor plan | House models |
| `houses/sabine/` | Sabine: exterior, interiors, floor plan | House models |
| `houses/vivienne/` | Vivienne: exterior, interiors, floor plan | House models |
| `amenities/` | Clubhouse, pool, courts, playgrounds (only ones that actually exist) | Amenities |
| `gates-security/` | Gates, guardhouse, patrols | Security |
| `community/` | Residents, events, church, street life | Community / About |
| `location/` | Vicinity map, master plan, nearby landmarks | Location |
| `gallery/` | Anything else worth showing | Gallery |

Tips:
- Landscape photos at least 1920px wide for `hero/`; 1200px is fine elsewhere.
- Any filename works. Descriptive names help, e.g. `molino-gate-day.jpg`, `charlotte-floorplan.png`.
- JPG for photos, PNG/SVG for logos and floor plans.
